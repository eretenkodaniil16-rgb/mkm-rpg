## Цель следующей версии: SHOWCASE-01 «Разрушенная сторожевая башня»

Разработать десяти–пятнадцатиминутный, воспроизводимый игровой сценарий, который отчётливо отличается от ванильного Minecraft и предыдущих QA-JAR. Игрок выбирает расу и класс, получает от NPC или находит ориентир к башне, сталкивается с двумя действительно разными типами врагов, использует классовое умение и видит новую анимацию (там, где её реальный рендер пройдет приёмку), получает и сохраняет последствие зачистки. Для команды разработчиков допустима защищённая GM-команда установки тестовой сцены; это НЕ считается полноценной природной генерацией мира. Проверять соло и в кооперативе на двоих. Для тестового мира предусмотрен вариант с отключёнными шейдерами, контролируемыми настройками и профилированием.

### Общий договор для ВСЕХ рабочих чатов

## Распределение волн и точный «кто ждёт кого»

**Волна A (можно параллельно):** QA / восстановление базового release train; Animation / перенос R07 geometry; Character / 2×2 meaningful actions; World+Environment / playable watchtower; Enemy / two genuinely distinct behaviours; UI / доступность A+B+C.  
**Волна B (после контрактов):** Combat / новый input+hit contract; Magic / executable actor effects и v4 grants; Performance / measurements, затем оптимизация; Sound/VFX / event hookup.  
**Волна C:** интегратор сверяет diff ownership, переносит Java/ресурсы по методам, выпускает экспериментальный RC; затем пользовательский тест, два клиента и контрольная миграция из КОПИИ сохранения.  
Сами разговоры ChatGPT не синхронизируются автоматически. GitHub issues/PR комментарии и ссылки на этот документ — общая коммуникация; поручения нужно передать чатам явно.

## Definition of Done

- В одном JAR есть не менее **четырёх визуально или механически заметных нововведений** по storyboard, а не просто registry classes.
- Все визуальные анимации и структуры реально проверены в Minecraft, не только в Blender/Python.
- SHA, версия Fabric/Java, полный modlist, версионная схема мира, CI и user QA известны.
- Один серверный путь урона и один путь XP. Два клиента не ломают квест/события, неизвестные идентификаторы не повреждают данные.
- A+B+C доступность учитывается, пользователю доступны безопасные клиентские настройки; недоделанные части не маскируются зелёным CI.
- До принятия этой версии **не менять default `main`**, где сейчас историческая NeoForge-основа; позже мигрировать Fabric release branch контролируемо.
