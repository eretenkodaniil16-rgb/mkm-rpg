# Тест MKM SHOWCASE-01 MNAE R07 в Minecraft (60 FPS)

**Важно:** использовать новый тестовый мир и отдельную установку Fabric 26.3. Не заменять установленную интеграционную QA5 основного мира без копии. В папке mods — ровно один mkm-rpg JAR.

1. Отключить шейдеры и изменение FOV, сохранить одну позицию камеры F5 и одинаковые настройки видео; записывать 1920×1080 60 FPS, желательно без переменной кадровой частоты. OBS Studio или Xbox Game Bar подойдёт при корректных настройках.
2. Поставить основную руку RIGHT и меч в **тот же активный слот** для всех трёх записей; offhand пуст, снять броню, стоять на плоском блоковом основании. Запись A: F8 OFF (C3 QA5), B: F8 ON/F9 OFF (шестичастная проекция тех же данных R07), C: F8 ON/F9 ON (17 частей). Для каждого ролика нажать **R только один раз** для первой фазы комбо и отметить время первого серверного тика. F9 ON без F8 ON недостаточно.
3. Проверить рукоять и кончик клинка на кадрах guard, anticipation, windup, pre-impact, impact, follow-through, recovery, settle и return; локти, колени, положение стоп, зазор клинок–голова/броня, отсутствие двойного тела, пропадания предмета и изменения камеры. Момент удара frame16 = 0.25 сек после старта при 60 FPS. Старые C3-данные и R07 оба используют серверный impact tick5 из 14.
4. Повторить на LEFT main arm, Steve/Alex и нестандартных скинах; затем offhand sword/shield, mainhand axe/pickaxe и броня. Эти случаи **должны перейти в честный fallback**, если не поддерживаются. Не оценивать визуально шаг без сравнения.
5. Для направлений G+W/G+A/G+S записать фронт, бок и назад: текущие визуальные прототипы не вращаются жёстко на 360°, но контакт стоп и правильная биомеханика ещё не утверждены.
6. Кооператив на двоих: второй игрок должен видеть хотя бы прежнюю/ванильную корректную анимацию. **Уникальный R07 clip для наблюдателя пока не передаётся, spectator gate PENDING.**
7. Проверить обычную ЛКМ по мобу/блоку и добычу блоков, отсутствие двойного урона, переоткрытие мира/измерение и сохранение персонажа v4. Ни одно изменение анимации не должно влиять на урон или hitbox.

### Автоматическое создание контактного листа из настоящих записей

После записи трёх видео и определения точных моментов начала первого R-удара:

```powershell
python tools/animation/r07/capture_f5_comparison.py --c3 c3.mp4 --six six.mp4 --r07 r07.mp4 --start-c3 5.20 --start-six 7.15 --start-r07 6.90 --out build/reports/mnae-f5
```

Это пример времени начала; используйте собственные точные значения. Нужен установленный FFmpeg/FFprobe. Скрипт откажется обрабатывать запись, если FPS не близок к 60. Он извлекает 27 настоящих кадров; при наличии Pillow создаёт контактный лист 3×9. Скрипт ничего не рисует вместо Minecraft, не заявляет автоматическую оценку красоты и не заменяет ручной разбор.

Только после проверки настоящей записи с корректным хватом и видимыми сегментами можно снять E4 visual gate. Не пересылать приватные видеозаписи в публичный PR без разрешения владельца.
